# Invitación — Nuxt

Invitación digital desarrollada con Nuxt, Vue y Tailwind CSS.

Requisitos:

- Node.js (>= 18 recomendado)
- npm

Comandos útiles:

```powershell
cd "C:\laragon\www\invitacion"
npm install
npm run dev     # servidor de desarrollo
npm run build   # build de producción
npm run preview # previsualizar el build
```

La aplicación se inicia desde `app/pages/index.vue` y sus componentes están en
`app/components/`.
